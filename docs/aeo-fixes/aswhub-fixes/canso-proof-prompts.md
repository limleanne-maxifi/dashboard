# CANSO & ATM Operator Proof Prompts
_The demo script that proves Maxifi's visibility solution · run live, capture verbatim_

## How to run (so the proof is credible, not cherry-picked)
1. Run **every prompt across all 5 engines**: ChatGPT (web-search mode on), Perplexity, Google Gemini, Microsoft Copilot, Claude (with web). Perplexity + ChatGPT show citations most clearly — best for screenshots.
2. Run **logged-out / incognito**, and run each prompt **2–3 times** (answers vary — note the variance; it's part of the story).
3. For each answer capture: (a) the verbatim text, (b) the **sources/citations panel**, (c) date + engine.
4. Score **citation share** per question = (answers that name the target entity ÷ total answers). Benchmark the hub against `airspaceworld.com` and `canso.org`.
5. Build the deck as a **before grid**: _Question | Who's cited now | Is CANSO/operator/hub present? (Y/N)_. The gaps ARE the pitch.

> Targets to slot into bracketed prompts — ANSPs: **NATS, DFS, DSNA, ENAIRE, ENAV**. Vendors: **Leidos, Thales, Indra, Frequentis, Rohde & Schwarz**. Body: **CANSO**.
